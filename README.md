# 🏘️ Melbourne Housing Market Analysis (EDA)
**Epsilon AI - Midterm Evaluation Project**

هذا المستودع (Repository) يحتوي على الكود المصدري ولوحة التحكم التفاعلية الخاصة بمشروع التقييم النصفي لمعسكر الذكاء الاصطناعي المقدم من [Epsilon AI](https://github.com/Epsilon-AI).

##  Project Overview & Objective
يهدف هذا المشروع إلى تطبيق دورة الحياة الكاملة لتحليل البيانات (Data Analysis Lifecycle)، بدءاً من تنظيف البيانات الخام (Dirty Data)، مروراً بالتحليل الاستكشافي (EDA)، ووصولاً إلى بناء لوحة تحكم تفاعلية (Dashboard) باستخدام `Python` و `Streamlit` لاستخراج رؤى اقتصادية واستثمارية من سوق العقارات في ملبورن.

##  1. Data Cleaning Phase (مرحلة تنظيف البيانات)
تم التعامل مع مجموعة بيانات غير نظيفة، وتم توثيق خطوات التنظيف في الكود، والتي شملت:
- **Handling Missing Values:** إزالة الصفوف التي تفتقر لمعلومات جوهرية للتحليل (مثل السعر `Price` أو المنطقة `Regionname`) باستخدام `dropna()`.
- **Removing Duplicates:** التأكد من جودة البيانات بإزالة العقارات المكررة `drop_duplicates()`.
- **Data Type Conversion:** تحويل عمود التاريخ `Date` إلى صيغة زمنية صحيحة لمعالجة السلاسل الزمنية بدقة `to_datetime()`.

##  2. Data Exploration Phase (مرحلة التحليل الاستكشافي)
بناءً على متطلبات التقييم، تم التحقيق في أكثر من **6 متغيرات (Variables)** من زوايا مختلفة:
1. `Price` (السعر)
2. `Regionname` (المنطقة)
3. `Distance` (المسافة عن المركز - CBD)
4. `Rooms` (عدد الغرف)
5. `Type` (نوع العقار)
6. `Date` (تاريخ البيع)

تم تطبيق كل من التحليل أحادي المتغير (Univariate) ومتعدد المتغيرات (Bi/Multi-variate) للإجابة على الأسئلة الاقتصادية المحددة في ملف العرض التقديمي.

##  3. Visualization Phase (الرسوم البيانية)
تم استيفاء شرط عرض **5 أنواع مختلفة على الأقل من المخططات (Plots)**، وتم اختيار البارامترات المناسبة لكل مخطط لتسهيل القراءة:
1. **Histogram (المدرج التكراري):** لتحليل (Univariate) وتوزيع الكتلة السعرية للمشترين.
2. **Bar Chart (المخطط الشريطي):** للمقارنة بين أنواع العقارات وحجم المبيعات.
3. **Boxplot (المخطط الصندوقي):** لتحليل (Bi-variate) يوضح توزيع الأسعار حسب كل منطقة جغرافية واكتشاف القيم الشاذة (Outliers).
4. **Scatter Plot (مخطط التشتت):** لتحليل (Multi-variate) يربط بين السعر، المسافة، وعدد الغرف في وقت واحد.
5. **Bubble Chart (المخطط الفقاعي):** لإبراز "المنطقة الذهبية" للاستثمار بناءً على كثافة المبيعات (حجم الفقاعة).
6. **Line Plot (المخطط الخطي):** لدراسة السلسلة الزمنية لمتوسط الأسعار عبر الأشهر.

##  4. Code Functionality & App Structure
تمت كتابة الكود البرمجي (Clean Code) وتقسيمه لضمان الأداء الأفضل:
- **Multi-page Streamlit App:** تم تقسيم الواجهة إلى 3 صفحات منفصلة (`Overview`, `Price_Analysis`, `Geo_Analysis`) باستخدام مجلد `pages/` لتنظيم الكود ومنع التكرار.
- **Session State & Caching:** تم استخدام `@st.cache_data` وحفظ البيانات المنظفة في ذاكرة المتصفح لمنع إعادة التحميل البطيء عند التنقل بين الصفحات.
